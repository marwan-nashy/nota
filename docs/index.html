Complete Feature Parity

Everything you need in a modern workspace, none of the weight

Block Editor & Slash Commands

Type / to insert headings, todos, quotes, code blocks, or callouts. Markdown shortcuts automatically convert into rich interactive blocks.

Relational Databases V2

Switch effortlessly between Table, visual Kanban Board, and Gallery View with cover cards. Features live status filters, dynamic multi-column sorting, and real-time calculation summary rows.

Visual Knowledge Graph

Obsidian-style 2D interactive force-directed graph. Explore connections across your workspace with physics simulation, zooming, node drag, and 1-click navigation.

Mermaid.js Diagrams

Insert /diagram blocks for flowcharts, sequence diagrams, state machines, and mindmaps from plain text with live SVG preview and syntax validation.

Encrypted Vault (AES-GCM-256)

Lock confidential pages with client-side 256-bit AES encryption via Web Crypto API. Password protection runs 100% locally with zero cloud exposure.

Daily Journal & Mini-Calendar

1-click "Today's Note" with pre-configured priorities, reflection prompts, and an interactive mini-calendar with note activity indicators.

Table of Contents & Outline

Insert /toc blocks for auto-generated heading outlines with smooth section jump scrolling, plus a slide-out sticky outline drawer for long-form reading.

Drag & Drop Block Reordering

Hover to grab any block with the 6-dot grip handle and drag to reorder. Includes keyboard/touch accessible Move Up and Move Down commands.

KaTeX Math Formulas

First-class KaTeX rendering engine. Insert /math blocks for complex LaTeX equations, physics matrices, and calculus formulas with live preview.

6 Handcrafted Themes

Switch between True OLED Pure Black (#000000 for battery saving), Catppuccin Mocha, Nord Arctic blue, Warm Sepia/Paper, Classic Light, and Modern Dark.

Backlinks & Connected Graph

Bi-directional reference tracking. See incoming links and mentions across your workspace at the foot of any page, turning your notes into an interconnected personal knowledge graph.

Multi-Workspace Hub

Create, switch, rename, and manage completely isolated workspaces with custom emojis. Keep personal, work, and side projects cleanly separated.

Hierarchical Tree & Templates

Infinitely nestable child pages with 1-click starter templates: Meeting Notes, Knowledge Reading List, Habit Tracker, and Brainstorm Scratchpad.

Offline PWA & Publication Print

Service Worker CacheStorage delivers 0ms offline loads. Export to clean Markdown or HTML, publication-grade print & PDF formatting, or full workspace JSON backup.

Arabic & RTL Support

New

Seamless 1-click toggle between English and Arabic. Complete right-to-left layout switching, bidirectional per-block automatic text flow, crisp typography, and Arabic starter templates.

Hide & Customize Features

New

Tailor Nota to your exact workflow. Easily toggle off any features you don't use (Graph, Diagrams, KaTeX Math, Relational Databases, Vault, Daily Notes, Backlinks, or TOC) to keep your workspace minimal and distraction-free.

In-App Update Checker

New

Stay current without intrusive background daemons. Check GitHub releases on demand directly from inside the app, review new version release notes, and download updates with a single click.

Focus Mode & Tabs Bar

v1.1

Eliminate all distractions with full-canvas Zen Mode (F11). Switch between documents effortlessly using the persistent Multi-Tab workspace strip.

Foldable Sections & Find/Replace

v1.1

Click chevron indicators on H1, H2, or H3 headings to fold or collapse document sections. Find and replace words instantly across your entire page with Ctrl+F.

Voice Memos & Local Media

v1.1

Record voice notes directly into your document via /voice with live waveform audio playback. Paste or upload images with zero cloud lock-in via high-speed IndexedDB storage.

Obsidian Import & P2P Sync

v1.1

Migrate effortlessly from Notion or Obsidian by dragging .md files directly into Nota. Sync workspaces peer-to-peer between mobile and desktop via offline encrypted QR code exchange.

Okapi BM25 & Related Notes

New

Industry-standard Okapi BM25 ranking engine in Quick Switcher (Ctrl+K) with highlighted snippets. TF-IDF cosine similarity suggests semantically related notes automatically.

Global Agenda & Calendar Export

New

Centralized task aggregator crawls all checkboxes and database milestones across your workspace into Agenda and Gantt views, with 1-click RFC 5545 .ics calendar feed export.

Database Formulas & Rollups

New

Create calculated columns with safe, zero-eval formula syntax (Price * Quantity, round(), if()). Automatic table footers display Sum, Average, Count, Min, and Max rollups.

Model Context Protocol (MCP)

New

Local JSON-RPC 2.0 MCP server bridge connects Claude Desktop, Antigravity, and AI agents directly to your private notes with 100% offline security. Includes interactive tool tester and script generator.

CapsuleCraft .eml Format

New

Single-file portable notes: export and import RFC 5322 MIME .eml files bundling markdown, images, and voice recordings in a format readable by Thunderbird, Outlook, and CapsuleCraft.

FAQ

Frequently Asked Questions

Can I try Nota directly in the browser without downloading?

Yes! Nota runs 100% client-side in any modern web browser without needing to download or install any software. Simply click Try Web App to explore your personal workspace, databases, Kanban boards, and templates immediately. All changes are stored locally in your browser and can be exported as Markdown, HTML, or JSON at any time.

Can I use Nota on Linux and Mobile (Android & iOS)?

Yes! For Linux, automated GitHub Actions pipelines produce native Debian packages (.deb) and universal standalone binaries (.AppImage). For Mobile, you can open the web app on any smartphone browser and select "Add to Home Screen" to install Nota as a standalone Progressive Web App (PWA) with full offline persistence and a responsive slide-out drawer layout. An automated Android APK pipeline is also available in our repository.

Why is Nota so much lighter than traditional note apps?

Traditional workspace apps are built on Electron, which bundles an entire copy of Google Chrome and Node.js with every window, consuming 600MB to 1.2GB of RAM. Nota is built on Tauri v2 with a compiled Rust backend and utilizes your operating system's native Evergreen WebView2, keeping idle RAM strictly under 35MB.

Does Nota require an internet connection?

No. Nota is 100% local-first. All your workspaces, pages, databases, and blocks are saved instantly on your machine with 0ms latency.

Is Nota open-source and free?

Yes, Nota is released under the GNU General Public License v3.0 (GPLv3). It is free to use, modify, and inspect forever.
